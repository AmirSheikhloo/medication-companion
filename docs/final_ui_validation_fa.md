# چک‌لیست پذیرش طراحی نهایی همراه دارو

این سند مربوط به **بازطراحی کامل پس از رد نسخهٔ CI124** است. مرجع بصری، یازده تصویر نهایی تأییدشدهٔ صاحب پروژه است؛ صرفاً تغییر رنگ یا گردکردن کارت‌های بتا پذیرفته نیست.

## ملاک پذیرش بصری

- رنگ اصلی `#075F60`، رنگ تأکیدی `#40E0D0`، پس‌زمینهٔ روشن `#F8FAFA`، کارت‌های نعنایی `#E1F8F6` و هشدار ملایم `#F8D37A`.
- فونت Noto Sans Arabic، چینش کامل راست‌به‌چپ و اعداد فارسی برای مقادیر نمایشی؛ نام فایل‌ها و شناسه‌های فنی استثنا هستند.
- نوار پایین چهارزبانه با حالت انتخاب **تیره، شامل نماد و عنوان داخل یک کپسول**؛ از نوار Material بتا استفاده نشود.
- نبود سربرگ مشترک بزرگ و تکراری؛ هر تب سربرگ مناسب همان صفحه را دارد.
- فهرست‌ها متراکم و قابل اسکن هستند؛ کارت جداگانهٔ بزرگ برای **تک‌تک نوبت‌های مصرف** استفاده نشود.
- افزودن دارو، جزئیات دارو، موجودی و ثبت اندازه‌گیری، صفحهٔ اختصاصی باشند.
- طرح در اندازهٔ ۳۶۰×۶۴۰ و با بزرگ‌نمایی متن ۱٫۳ بدون سرریز یا مخفی‌شدن اکشن‌های اصلی کار کند.

## معیار تحویل

۱. `flutter analyze` بدون اخطار؛ ۲. تمامی تست‌های واحد/ویجت موفق؛ ۳. APK Android موفق؛ ۴. **حداقل ۱۲ تصویر از UI واقعی Flutter** در خروجی CI برای تطبیق چشمی؛ ۵. بازبینی دستی نهایی روی شبیه‌ساز توسط صاحب پروژه.

سبزشدن تست‌های نرم‌افزاری به‌تنهایی مساوی تأیید شباهت بصری نیست. تا زمان تطبیق تصاویر و تأیید کاربر، Pull Request باید در حالت Draft بماند.
