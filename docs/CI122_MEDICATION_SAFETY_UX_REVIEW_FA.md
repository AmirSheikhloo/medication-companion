# CI122 — قرارداد بازبینی تغییرات دارو و موجودی

این شاخه آزمایشی است. اجرای CI و آزمون روی Android شرط پذیرش است؛ این سند به معنی موفقیت آزمون‌ها نیست.

## واحد و محاسبه
- واحد مصرف برای نوبت‌های یک برنامه مشترک؛ موجودی مایعات در میلی‌لیتر.
- سی‌سی و میلی‌لیتر برابر؛ قاشق چای‌خوری مدرج ۵ و غذاخوری مدرج ۱۵ میلی‌لیتر. قاشق مرباخوری نیازمند ظرفیت واقعی ابزار مدرج است. قاشق خانگی قابل اعتماد نیست.
- قطره و پاف و سایر واحدهای شمارشی از موجودی همان واحد کم می‌شوند. تبدیل قطره به حجم یا IU به میلی‌گرم بدون اطلاعات فرآورده ممنوع است.
- مثال‌های پذیرش: ۱۲۰ - ۱۵ = ۱۰۵ میلی‌لیتر؛ نیم قاشق ۵ میلی‌لیتری = ۲٫۵ میلی‌لیتر؛ ۲ قاشق مدرج ۷٫۵ میلی‌لیتری = ۱۵ میلی‌لیتر؛ ۳ قطره از ۶۰ قطره = ۵۷ قطره. Undo دقیقاً کسر واقعی را بازمی‌گرداند.
- ورودی صفر، منفی، اعشار خارج از دقت، ظرفیت نامعلوم قاشق و واحد ناسازگار باید رد شوند. هنگام تغییر واحد پیش از ثبت، مقادیر قبلی نباید به واحد جدید تعبیر شوند.
- قدرت دارو (مثلاً ۵۰۰ mg) معادل تعداد قرص یا حجم مایع نیست.

## آزمون‌های پذیرش
| سناریو | رفتار مورد انتظار |
|---|---|
| انتخاب واحد در افزودن و ویرایش | نوبت‌ها واحد یکسان دارند و موجودی با واحد سازگار ثبت می‌شود |
| موجودی ناکافی | کسر منفی و ثبت اشتباه جلوگیری شود؛ ثبت بدون کسر صریح باشد |
| پایان بسته یا بایگانی آن | سوابق حفظ شوند؛ بسته واجد شرایط دیگر انتخاب شود؛ در نبود آن هشدار |
| اولین بسته | اولین بسته معتبر و دارای موجودی انتخاب شود |
| حذف بسته | مسیر کاربر حذف نرم و قابل بازگردانی؛ داده‌های مصرف محفوظ |
| حذف دارو از فهرست | حذف نرم؛ بازگردانی پس از ثبت واقعی؛ پروفایل دیگر دست‌نخورده |
| تاریخ انقضا وارد نشده | گزینه هشدار قبل از انقضا نشان داده نشود |
| تعیین فاصله هشدار بیش از روزهای باقی‌مانده | رد تنظیم جدید؛ تنظیم قبلی معتبر بی‌دلیل پاک نشود |
| انقضای دقیق/ماهانه، تغییر روز | محاسبه تقویمی مطابق دقت ثبت؛ منع انتخاب بسته منقضی |
| چند هشدار | تگ و رنگ و زنگوله متناسب؛ باز کردن همان دارو |
| عدم نمایش هشدار | فقط هشدار همان وضعیت پنهان؛ وضعیت واقعی موجودی/انقضا تغییر نکند |
| رفع کمبود و تکرار | هشدار دوباره قابل نمایش |
| قبل از موعد، تغییر ۱۴ به ۱۶ در ساعت ۱۲ | اعمال امروز در صورت نبود تداخل |
| نوبت گذشته یا رویداد ثبت‌شده/بازگردانده‌شده | تغییر مؤثر بر گذشته از فردا؛ شناسه و تاریخچه قدیمی محفوظ |
| ویرایش بدون تغییر برنامه | نسخه تکراری ایجاد نشود |
| تغییر نام همان فرآورده | تأیید صریح و ثبت نام قبلی/جدید؛ تاریخچه بازنویسی نشود |
| تغییر ماده یا قدرت | داروی مستقل جدید؛ انتقال خودکار سوابق/بسته ممنوع |
| ثبت نامطمئن | هیچ کسر خودکار؛ شمارش در بازه سوابق و راهنمای بررسی |
| مصرف بدون کسر | ثبت صریح؛ شمارش در بازه سوابق؛ اختلاف واقعی را اثبات نمی‌کند |
| تعداد زیاد نوبت | خلاصه خوانا و تعداد باقی‌مانده |
| تعداد زیاد سوابق | بارگذاری مرحله‌ای و محدود |
| عملیات آفلاین | ابتدا commit پایگاه داده سپس نمایش نتیجه؛ همگام‌سازی یادآورها جدا |
| آلارم تنها / اعلان تنها / هر دو / هیچ‌کدام | تنظیم مستقل؛ رفتار واقعی با مجوزهای Android آزموده شود |
| حالت تاریک | تغییر تم، حفظ تنظیم و بررسی خوانایی همه صفحه‌ها با دستگاه واقعی |
| بازیابی نسخه پشتیبان | حفظ تنظیمات و سوابق؛ عدم تغییر اجباری نسخه schema در این شاخه |

## محدودیت‌های تأیید
- تبدیل خودکار قطره به میلی‌لیتر و تبدیل بر اساس غلظت پیاده نشده‌اند؛ نیاز به داده معتبر خاص فرآورده دارند.
- آلارم تمام‌صفحه از مسیر اعلان Android اجرا می‌شود؛ معادل کامل برنامه ساعت سیستم (صدای پیوسته، snooze، همه حالات مجوز و قفل) هنوز تضمین نشده.
- تحلیل بازبینی صرفاً شمارش ثبت‌های نامطمئن و بدون کسر است، نه تشخیص پزشکی یا اثبات اختلاف موجودی.
- بررسی بصری همه صفحات، زمان‌سنجی عملکرد، چرخه بازگشایی و پایداری آلارم روی دستگاه لازم است.
